**件名：** Domane+ AL5 の Di2 化（1×11）作業のご相談

サイクルショップフクハマ
横山様

お世話になっております。山本です。

先日はリアホイールの組み換えでお世話になり、ありがとうございました。

同じ Domane+ AL5 について、今度はコンポーネントを Di2 の 1×11 仕様に組み替えたいと考えております。
部品はほぼ手元にあり、途中まで自分で進めておりますが、内装配線やブレーキのブリーディングなど
専門工具と経験が必要な工程は貴店にお願いしたく、対応の可否とお見積り、納期の目安をご相談させてください。

【目標の構成】
・変速：1×11（ST-RX815 L/R ＋ RD-M8050-GS、スプロケット ZTTO 11-46T、チェーン KMC X11）
・Di2 電装：BT-DN110／EW-RS910／SM-JC41／EW-WU111、配線 EW-SD50 ×6
・ハンドル：baracan MISSION 一体型（400／90）・フル内装
・ブレーキ：105 油圧キャリパーを流用（ミネラルオイル）

【現在の状態】
・旧コンポーネントは取り外し済み、リアホイールに 11-46T とローターは装着済みです。
・一体型ハンドルは仮組み済み（コラム未カット）、フレーム内の内装ライナーは通してあります。
・前輪（チューブレス）のビード上げは未実施です。
・BB トルクセンサー（HYENA 57T031）が故障し、取り外してあります（ケーブル被覆が裂けた状態）。
　BB ユニットを兼ねているため、現状ではクランクが取り付けられません。

【お願いしたい作業】
1. BB トルクセンサーの交換品（または補修）の手配のご相談
　　Trek 経由で同型番が入手できるか、納期と費用をご確認いただけますでしょうか。
2. RD-M8050-GS の取付（ハンガー点検を含む）
3. 一体型ハンドルへのホース・Di2 配線の内装と ST-RX815 の取付
4. Di2 配線一式とジャンクション類の設置・固定
　　ダウンチューブはバッテリーが占有するため、ユニットは BB 周辺に集約する想定です。
　　手持ちの EW-SD50 で長さが足りない経路（EW-RS910→SM-JC41、SM-JC41→RD）がありそうなので、
　　実車で確認のうえ、必要な長さのケーブル手配もお願いしたいです。
5. ブレーキホースの取り回し直し（新品）とブリーディング
6. E-TUBE PROJECT での設定（ユニット認識・FW 更新・スイッチ割当・変速調整）
7. センサー復旧後：クランク・ナローワイドチェーンリング（歯数は要相談）の取付、チェーンの取付
8. 前輪チューブレスのビード上げとシーラント注入
9. 試走でポジションを確定したうえでのコラムカット（アルミコラム）、バーテープ巻き、最終チェック

作業の順序として、コラムカットとレバーの本締めは試走でポジションを決めてから、という形を希望しております。
一部の作業のみのご対応でも構いません。

【部品について】
主要部品（STI、RD、Di2 ユニット一式、EW-SD50、チェーン、ハンドル）は手元にあり、持ち込みます。
以下は未手配ですので、貴店でご用意いただけるとありがたいです。
　BB トルクセンサー／ナローワイドチェーンリング／チェーンリングボルト／ブレーキホース＋オリーブ・インサート／
　ミネラルオイル／不足分の EW-SD50／スターファングルナット／シーラント／バーテープ
クランクは既存品の流用可否（スピンドル規格・チェーンライン）から、あわせてご判断いただけますと幸いです。

【お伺いしたいこと】
・持ち込み部品での作業をお受けいただけるか
・センサー無しでも進められる作業（配線・ブレーキ・E-TUBE の電気設定など）を先行していただけるか
・概算のお見積り（工賃・部品代）と、センサーの納期を含めたおおよその期間
・車体をお預けするタイミングと期間の目安

前回同様、しばらく車体を使えないことは承知しておりますのでご心配なく。
