# Domane+ AL5 ／ Di2化 施工手順アプリ

Trek Domane+ AL 5（size 54・HyDrive リアハブモーター）を 1×11 の Di2 化する際の施工手順を、
**3Dで確認しながら進められる単一HTMLのWebアプリ**です。スマートフォン縦持ちでの現場利用を前提にしています。

**公開URL: https://tcta-tottori.github.io/road-bike-Di2/**

`index.html` をブラウザで開くだけで動作します。ビルド不要・外部通信なし・オフライン可。

### GitHub Pages の有効化（初回のみ手動）

リポジトリの **Settings → Pages → Build and deployment → Source** を設定してください。

- **GitHub Actions** を選ぶ … `.github/workflows/pages.yml` により、既定ブランチへの push で自動デプロイされます（推奨）。
- **Deploy from a branch** を選ぶ … branch = 既定ブランチ、folder = `/ (root)`。ワークフロー不要で直下の `index.html` がそのまま公開されます（`.nojekyll` 配置済み）。

※ Actions 方式でデプロイが権限エラーになる場合は、**Settings → Actions → General → Workflow permissions** を
「Read and write permissions」にしてから再実行してください。

## 機能

- **3Dビューア** — 1本指ドラッグで回転、2本指ピンチで拡大・移動。工程ごとに該当部位だけを点灯させ、
  それ以外は減光。カメラは端末の画面サイズに合わせて自動フィットします。
- **14工程のチェックリスト** — STEP 0〜13（実車の現況から始まる残作業のみ）。作業項目・工具・締付トルク（参考値）・注意点を工程ごとに表示。
  チェック状況は端末の localStorage に保存され、進捗率がヘッダーに出ます。
- **配線タブ** — 手書きSVGの配線図と、EW-RS910／SM-JC41 の**取付位置シミュレーション**。
  位置を変えると3Dの経路と経路長概算がその場で切り替わり、指定長で成立するかを比較できます。
- **部品タブ** — 部品リストから該当部位に3Dでジャンプ。要確認・未確定事項の一覧付き。
- **印刷** — 画面表示とは別に、A4縦1枚組の施工資料（構成表・配線図・全工程・要確認事項）を出力します。
  資料タブの「印刷 / PDF」またはブラウザの印刷から。
- **PWA（アプリとしてインストール）** — ホーム画面に追加すると全画面で起動し、**圏外でも動作**します。
  Android/Chrome は資料タブの「ホーム画面に追加」ボタンまたはメニューから、iPhone/Safari は共有→「ホーム画面に追加」。
- **解説の自動再生（動画モード）** — 3D右上の「解説」または各工程の「▶ この工程から解説を再生」で、
  14工程を順に自動再生します。カメラが自動で寄り、対象部位が点灯し、配線は経路に沿って伸び、
  ホイールやクランクは回転します。字幕に作業項目が順に表示されます（全体で約2分半）。
  再生バーで前後の工程・一時停止・速度（0.5〜2.0×）を操作でき、**「● 録画」で .webm 動画として保存**できます
  （canvas.captureStream + MediaRecorder／音声なし／非対応端末ではボタン非表示）。
- **表示の切替** — 本文をスクロールすると3Dを畳んで全画面表示になります。上に戻しても自動では開かず、
  右下の「3D図」ボタンを押したときだけ復帰します。「名称」ボタンで部品名ラベルの表示/非表示を切り替えられます。

## 技術メモ

- **単一HTMLファイル**。ライブラリ・CDN・フォント・画像を一切使いません（CSPの厳しい環境でもそのまま動作）。
- 3Dは **canvas 2D 上の自作ソフトウェアレンダラ**です。
  - 円筒・直方体・円板・トーラス・リム帯・連続チューブのプリミティブから車体を組み立て
  - 面の重心depthでソートする画家のアルゴリズム＋フラットシェーディング
  - 強調部は非強調部の後に描くため、フレーム内部の配線も透けて見えます（「透視」ボタンで切替）
  - 約2,700ポリゴン／iPhone級の端末で60fps目安（実測：1280×800 デスクトップで約15ms/フレーム）
- 配線経路は3D上のポリラインで持っており、**経路長はモデルから実際に計算**しています。
- 図はすべて手書きSVG（Mermaid不使用）。
- 陰影はキーライト＋補助光＋リムライト＋鏡面反射、裏面カリング、接地影つき。
  ハーフベクトルは毎フレーム固定・べき乗は二乗の繰り返しで近似し、面あたりの計算を抑えています。
- 解説再生はメッシュ単位の変形（平行移動・Z軸回転）と、配線ポリラインの部分描画で表現しています。
  字幕とシークバーは canvas に直接描くため、録画した動画にもそのまま入ります。
- PWA は `manifest.webmanifest` ＋ `sw.js`（stale-while-revalidate）。
  表示はキャッシュから即返し、裏で更新して次回起動に反映します。

## 重要な注意

- 3Dは**模式図**です。CADデータではありません。ジオメトリは Domane AL 系の一般的な数値
  （size 54：スタック575／リーチ374／CS430／WB1002 など）に基づく参考モデルで、実車の公称値とは差異があります。
- **締付トルクはすべて参考値**です。必ず各メーカーの最新ディーラーマニュアルを確認してください。
- 配線の経路長は模式モデル上の計算値で、曲げR・余長・コネクタ長を含みません。
  誤差を±15%と見込み、その帯に入るものは「要実測」と表示しています。**発注・切り回しの前に必ず実測**してください。

### 机上検討で判明した論点

`③ EW-RS910 → SM-JC41（指定 700 mm）` は、EW-RS910 をバーエンド、SM-JC41 をダウンチューブ下部とした場合、
モデル概算で **約800〜1,100 mm** となり届かない可能性が高い経路です。
配線タブのセレクタで比較できますが、以下はトレードオフの関係にあります。

- EW-RS910 をダウンチューブ装着に変更 → ② 250 mm が足りなくなる
- SM-JC41 をヘッドチューブ寄りに上げる → ⑤ 600 mm が足りなくなる
- ③ を 1,000 mm 前後に変更する

いずれも**実車でライナーを通した実測**で確定させてください。

### 現況（2026-08-05・実車写真より）

手順は**この現況から始まる残作業だけ**で構成しています（旧コンポーネントの取り外しとカセット装着は完了済みのため省略）。

完了：旧コンポーネントの取り外し／リアホイールへ ZTTO 11-46T とローター装着／baracan MISSION の仮組み（コラム未カット・ステム上に35〜40mm突き出し）／リアキャリア装着／内装ライナー通し済み
未実施：前輪（カーボンディープ・Pirelli タンサイド）のビード上げ／クランクとチェーンリングの確定／RD 取付以降の全工程

工程の順序で注意した点：**コラムカットは仮組みでの試走でポジションを確定させてから**行うため、後半（STEP 12）に置いています。
バーテープとレバーの本締めも同じ理由で最後です。

> **コラムカット**：本車はフォーク＝カーボン／**コラム＝アルミ**のため、スターファングルナットが使用できます
> （圧入深さは上端から約15mmが目安）。なお一般則として、カーボンコラムにスターナットは使用不可です。

### ユニット配置と EW-SD50 の必要長

ダウンチューブは e-bike メインバッテリーが占有するため、Di2 ユニットは **BB周辺〜シートチューブ下部に集約**する前提です
（配線タブの「ユニットの集約」で分散配置と比較できます）。この配置でのモデル概算と推奨長：

| | 経路 | 手持ち | モデル経路長 | 推奨 |
|---|---|---|---|---|
| ① | 左レバー → 右レバー | 400 | 約430 | 450〜500 |
| ② | 右レバー → EW-RS910 | 250 | 約198 | 250（そのまま） |
| ③ | EW-RS910 → SM-JC41 | 700 | 約1,092 | **1,200** |
| ④ | SM-JC41 → BT-DN110 | 200 | 約154 | 200（そのまま） |
| ⑤ | SM-JC41 → RD | 600 | 約667 | **750** |
| ⑥ | SM-JC41 → EW-WU111 | 150 | 約79 | 150（そのまま） |

推奨長＝経路長＋余長（40mm または8%の大きい方）を EW-SD50 の規格長へ切り上げたもの。**発注前に実測で確認**してください。

その他の未確定事項（チェーンリング歯数、ダウンチューブ内に配線を通す隙間の有無、
EW-WU111 のアルミフレーム内装による通信距離低下 など）は、アプリの「部品」タブ末尾に一覧があります。
